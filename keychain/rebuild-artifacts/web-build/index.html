Try: Cndl for candles, 1W / 1M / 1Y for ranges, Rotate for the landscape chart, Auth for the authenticator, Price for the big-price view. Prefer a guided tour? Watch the 90-second video.

This is the actual C++ sketch from paperstreet-keychain.ino running in your browser — same code, same chart math, same colours, same smooth anti-aliased fonts as the real device. Touch and network are simulated. Data comes from the same public sources as the real device (CoinGecko, Coinbase, paperstreetbtc.com, mempool.space); if the live fetch fails it falls back to a snapshot from 24 Nov 2026 ~11:03 EST. The clock and Authenticator code run off your device’s real clock.
